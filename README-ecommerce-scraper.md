# AI-Powered Intelligent E-Commerce System & Product Data Scraper

A system that collects, processes and analyses product data from multiple e-commerce platforms.

- **Scraping:** automated web scraping of dynamic websites using Selenium, Scrapy and BeautifulSoup.
- **Pipeline:** an automated product data collection pipeline (modelled on the Bol.com page structure) that extracts and organises product information.
- **Output:** clean, consistent product data ready for downstream analytics and recommendation systems.
- **Tech stack:** Python, Selenium, Scrapy, BeautifulSoup.
